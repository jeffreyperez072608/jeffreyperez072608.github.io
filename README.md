# jeffreyperez072608.github.io

The public pages for **StickSquad**, a desktop companion for Windows:

- [Home](https://jeffreyperez072608.github.io/)
- [Privacy Policy](https://jeffreyperez072608.github.io/privacy.html)
- [Terms of Service](https://jeffreyperez072608.github.io/terms.html)

These are the pages Google's OAuth consent screen links to.

This is a **user site**, so it serves from the root of
`jeffreyperez072608.github.io`. That matters: Google Search Console verifies a
domain by fetching a file from its root, and the OAuth consent screen will only
accept an authorised domain that is verified. A project site (served from
`/<repo>/`) cannot answer for the root, which is why the site lives here.

The application source is not part of this repository.
