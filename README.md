# jeffreyperez072608.github.io

The public pages for **StickSquad**, a desktop companion for Windows, served at
**https://sticksquad.net/**:

- [Home](https://sticksquad.net/)
- [Privacy Policy](https://sticksquad.net/privacy.html)
- [Terms of Service](https://sticksquad.net/terms.html)

These are the pages Google's OAuth consent screen links to.

The `CNAME` file is what puts this site on `sticksquad.net`; GitHub Pages then
redirects `jeffreyperez072608.github.io` there. Google will not accept a
`github.io` address as an app's home page or privacy policy, because nobody can
own a subdomain of it, so the site has to be on a domain the publisher owns.
The domain's DNS (at GoDaddy) points at GitHub Pages, and it is verified in
Google Search Console as a Domain property and in GitHub's verified domains,
both by TXT record.

The application source is not part of this repository.
